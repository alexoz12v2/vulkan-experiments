# Daily Exercises

Repository collections for my daily challenged, which will result in a notes markdown file and an anki question, still documented here

- all these exercises don't allow any form of AI usage. Internet research is allowed though, not for complete solutions, but for books,
  instruction/function/library references/documentation, ...
- all these exercises start from absolute scratch, or some start with some shared library/template when the setup is too big, from 
  exercises you've done before (Eg. a vulkan exercise can hardly start from scratch)
  - wikipedia is not in the allowed site list
  - if you can't finish it on time, no sweat, you'll resume next morning. Don't close it later in the day (eg work day, weekend is fine continuing)
  - if, after the exercise, you want to study a little bit on a linked argument, no more than 30 minutes (Eg assembly <-> ELF file format)
    - in that case, an additional Anki card must be produced
- each exercise folder will contain a `README.md` file with 2 paragraphs, besides the initial prompt
  - specify in which OS this exercise should be done and he tools used
  - `Notes` in which notes, devlog, algorithm specification will go
  - `Result` produced artifacts and an `Anki` subparagraph in which I'll insert the anki front and back (specify if type or straight ans)
